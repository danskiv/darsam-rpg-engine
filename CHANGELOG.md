# Darsam RPG Engine - Changelog

## [2.4.2-dev] - 2026-08-22 (Branch: feat/encounter-ecosystem)
### Added
- **Infinite Dynamic Chapter & Floor Progression Engine:** Converted static 5-chapter table into a continuous scaling milestone engine (every 8 exploration steps unlocks the next chapter across 5 increasing dungeon floor depths), ending late-game chapter stagnation.
- **Narrative & Encounter Diversity Enhancements:** Synchronized deep dungeon themes (Floors 1–5: Upper Crypts, Waterways, Necropolis, Void Chasms, and Primordial Genesis Sanctums).

## [2.4.1-dev] - 2026-08-22 (Branch: feat/encounter-ecosystem)
### Added
- Expanded Cross-Class Secret Awakening Tree (Common to Mythic tiers).

## [2.4.0-dev] - 2026-08-22 (Branch: feat/encounter-ecosystem)
### Added
- Dynamic Living Crypt Merchant & Barter Encampment UI with dual Buy/Sell tabs.
- Haggling via Charisma Check (`CHA Check vs DC 11`).
- One-Click "Sell All Junk" Engine.
