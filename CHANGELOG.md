# Darsam RPG Engine - Changelog

## [2.4.0-dev] - 2026-08-22 (Branch: feat/encounter-ecosystem)
### Added
- **Encounter Ecosystem Engine (PRD & Mechanics Spec):** Drafted and established full specifications for Living Crypt Merchants, Treasure Chests & Mimic Traps, Branching Crossroads, Campfires, and Shrines of Fate.
- **Dedicated Feature Branch:** Created and pushed `feat/encounter-ecosystem` to GitHub to safely develop and test the new encounter systems before merging via Pull Request.
- **Weighted Encounter RNG Architecture:** Designed a 6-tier probabilistic room encounter generator (Combat, Crossroads, Chests, Merchants, Campfires, Shrines).
